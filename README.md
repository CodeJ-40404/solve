## 可行方法1
使用codex/trae cn等AI IDE来帮助你寻找问题所在
建议提示词
```
请协助分析并解决网课软件的全屏强制锁定问题：该软件在未进入教室阶段可通过Windows徽标键（Win键）绕开全屏限制，但进入教室后会自动触发强制全屏+窗口置顶模式，此时系统大量可以退出全屏的热键失效，且Win键被完全屏蔽无法使用。请首先定位该软件的配置文件、注册表项或本地存储的参数文件，查找与窗口模式、全屏锁定、热键拦截相关的配置项，分析强制全屏和热键屏蔽的实现逻辑，验证是否存在可修改的配置参数来解除该强制限制，同时记录配置文件的路径、格式和相关关键字段信息。 
 
 注，我指的为C:\hetao,并不是其他软件，谢谢
```
路径可能有出入，请根据自己实际情况更改
